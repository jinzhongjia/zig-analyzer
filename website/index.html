A language server
for Zig.

Built on an incremental query engine. Errors come only from Zig itself, comptime is evaluated, and the project model comes from the official build system.

// Features

Accuracy first: results are correct and complete, never truncated or approximated for speed.

Diagnostics from Zig

Errors come only from Zig itself: in-process AstGen while typing and zig build on save. Inactive code can optionally be marked.

Comptime evaluation

Generics and type constructors are evaluated, and generic function bodies are analyzed with the instances from their call sites.

Build system integration

The project model comes from the official build system protocol. Files without build.zig use single-file mode.

Navigation

Goto definition, declaration, and type definition; find references; document highlight; document and workspace symbols.

Editing

Completion with auto-import and snippets, hover, signature help, inlay hints, and semantic tokens.

Refactoring

Rename, plus code actions for unused names, var to const, missing switch prongs and struct fields, and organizing imports.

Formatting

Identical to zig fmt, for .zig and .zon, with one edit per changed region.

ZON files

Highlighting, formatting, and diagnostics in any .zon; completion, goto, and inlay hints for typed imports and build.zig.zon.

Opt-in hints

Naming checks from the Zig style guide with safe rename fixes, and unused private declarations. Comments suppress them per line or range.

// Install

Each package installs the ReleaseSafe build of the latest release, with its debug information.

macOS and Linux, with Homebrew:

brew install jinzhongjia/tap/zig-analyzer

x86_64 and aarch64, from the AUR, with a helper such as yay:

yay -S zig-analyzer-bin

x86_64 and aarch64, with Scoop:

scoop bucket add jin https://github.com/jinzhongjia/scoop-bucket
scoop install jin/zig-analyzer

Each release has an archive for x86_64 and aarch64 on Linux, macOS, and Windows, signed with minisign and with a build provenance attestation. Put zig-analyzer in PATH, and keep the debug information file next to it.

minisign -Vm zig-analyzer-<version>-<target>-ReleaseSafe.tar.gz -p minisign.pub

Requires Zig 0.17.0 or 0.17.1:

git clone https://github.com/jinzhongjia/zig-analyzer
cd zig-analyzer
zig build -Doptimize=ReleaseSafe
