# Changelog

All notable changes to zig-analyzer. Versions follow [Semantic Versioning](https://semver.org/), independent of Zig versions; the section of each version is also the notes of its [GitHub release](https://github.com/jinzhongjia/zig-analyzer/releases). New sections are generated by `tools/changelog.sh` from the labels of the merged pull requests.

## [0.1.1-rc.1](https://github.com/jinzhongjia/zig-analyzer/releases/tag/v0.1.1-rc.1) - 2026-11-11

A release candidate that tries the new release process; the server is the same as in 0.1.0.

### Features

- Each platform also has a `ReleaseFast` build next to the recommended `ReleaseSafe` one; the README explains which to pick ([#310](https://github.com/jinzhongjia/zig-analyzer/pull/310)).
- The archives and `SHA256SUMS` are signed with minisign; verify them with `minisign.pub` from the repository ([#310](https://github.com/jinzhongjia/zig-analyzer/pull/310)).
- Each archive has a build provenance attestation (`gh attestation verify`), is smoke-tested on its own platform before the release is published, and includes `CHANGELOG.md` ([#311](https://github.com/jinzhongjia/zig-analyzer/pull/311)).

## [0.1.0](https://github.com/jinzhongjia/zig-analyzer/releases/tag/v0.1.0) - 2026-11-11

The first release of zig-analyzer, a language server for Zig built on an incremental query engine. Supports Zig 0.17.0 and 0.17.1.

### Features

- **Diagnostics** come only from Zig itself: in-process AstGen while typing, and `zig build` over the build system protocol on save. Files without `build.zig` are compiled in single-file mode. Inactive code can optionally be marked.
- **Comptime evaluation**: generics and type constructors are evaluated, and generic function bodies are analyzed with the instances from their call sites.
- **Build system integration**: the project model comes from `zig build --listen=-`, including dependency packages, generated files, and sub-projects that depend on the root by `.path`.
- **Navigation**: goto definition / declaration / type definition, find references, document highlight, document and workspace symbols.
- **Editing**: completion with auto-import and snippets, hover, signature help, inlay hints, and semantic tokens.
- **Refactoring**: rename, and code actions for unused names, parameters, and captures, `var` to `const`, missing switch prongs and struct fields, extracting constants, converting string literals, and organizing imports.
- **Formatting** identical to `zig fmt`, for `.zig` and `.zon`.
- **ZON files**: highlighting, formatting, and diagnostics in any `.zon` file; completion, goto, and inlay hints for files imported with a result type and for `build.zig.zon`; completion and option descriptions in `zig-analyzer.zon`.
- **Structure**: folding ranges and selection ranges.
- **Naming checks** (opt-in), based on the Names section of the Zig style guide, with safe rename fixes.
