*zig-analyzer.txt*  The zig-analyzer language server for Zig

==============================================================================
INTRODUCTION                                              *zig-analyzer*

Configures the zig-analyzer language server with |vim.lsp.config()| and adds
|:ZigAnalyzer| for the server's own requests. Requires Neovim 0.12 or later,
`zig-analyzer` in PATH, and Zig 0.17.0 or 0.17.1.

==============================================================================
INSTALLATION                                  *zig-analyzer-installation*

With |vim.pack|:
>lua
    vim.pack.add({ 'https://github.com/jinzhongjia/zig-analyzer.nvim' })
    require('zig-analyzer').setup()
<
With lazy.nvim:
>lua
    { 'jinzhongjia/zig-analyzer.nvim', ft = 'zig', opts = {} }
<
The plugin is developed in `editors/nvim` of jinzhongjia/zig-analyzer, which
jinzhongjia/zig-analyzer.nvim mirrors.

==============================================================================
SETUP                                                *zig-analyzer-setup*

>lua
    require('zig-analyzer').setup({
      -- Any field of |vim.lsp.Config|; `cmd` defaults to { 'zig-analyzer' }
      settings = {
        build = { args = { '-Dtarget=aarch64-linux' } },
        inlay_hints = { parameters = false },
      },
    })
<
`settings` holds the options of `zig-analyzer.default.zon` as a Lua table
(`.build = .{ .args = .{"-Dfoo"} }` is `{ build = { args = { '-Dfoo' } } }`,
enum literals are strings). `zig-analyzer.zon` in the project root takes
precedence over them.

`setup()` calls |vim.lsp.config()| and |vim.lsp.enable()|. Without it, the
configuration in `lsp/zig_analyzer.lua` can also be used directly:
>lua
    vim.lsp.enable('zig_analyzer')
<
The workspace root is the nearest directory containing `build.zig` or `.git`.
A file that a running server reports as a dependency library file (the Zig
installation, a fetched package, a generated file), such as one reached by
going to a definition in the standard library, is attached to that server
instead of starting another one for its own root.

==============================================================================
COMMANDS                                             *zig-analyzer-commands*

                                                            *:ZigAnalyzer*
:ZigAnalyzer status          Show the server status (queries, memory).
:ZigAnalyzer fileStatus      Show how the server treats the current file:
                             origin, modules, projects, last build.
:ZigAnalyzer syntaxTree      Show the syntax tree of the current file.
:ZigAnalyzer moduleGraph     Show the module graph of the projects.
:ZigAnalyzer reloadWorkspace Rerun `build.zig` and reload the projects.
:ZigAnalyzer restart         Restart the server (|:lsp-restart|).
:ZigAnalyzer log             Open the LSP log.

Run |:checkhealth| zig-analyzer to check the server and Zig executables.
